# 📝 My Blog Application

A simple and responsive blog application built to practice web development concepts and create, manage, and display blog content through a clean user interface.

## 🚀 Features

* 🏠 Clean and simple home page
* 📝 Create and publish blog posts
* 📖 View blog posts
* ✏️ Edit existing posts
* 🗑️ Delete posts
* 📱 Responsive user interface
* ⚡ Simple and easy-to-use design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Node.js
* Express.js
* EJS

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project

```bash
cd My-Blog-App
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Application

```bash
node index.js
```

Open your browser and visit:

```text
http://localhost:3000
```
